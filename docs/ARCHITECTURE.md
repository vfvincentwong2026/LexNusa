## 2. 核心技术选型与决策

### 2.1 为什么选择 Cloudflare 全栈？

| 对比维度 | 传统云（AWS/GC） | Cloudflare | 决策 |
| :--- | :--- | :--- | :--- |
| 运维成本 | 需管理 EC2/RDS 等 | 零运维，Serverless | ✅ Cloudflare |
| 全球延迟 | 需多区域部署 | 300+ 边缘节点默认加速 | ✅ Cloudflare |
| 成本 | 按资源使用量计费 | 免费额度充足（见成本分析） | ✅ Cloudflare |
| 开发体验 | 多种 SDK 与配置 | Wrangler CLI 统一管理 | ✅ Cloudflare |
| 协议支持 | 需自建 WebSocket/SSE | Workers 原生支持 SSE/WebSocket | ✅ Cloudflare |

### 2.2 数据存储选型

| 数据类型 | 选型 | 替代方案（被否决） | 决策理由 |
| :--- | :--- | :--- | :--- |
| 法规节点与关系 | **D1（SQLite 分布式）** | Neo4j（需自建或 Aura） | D1 支持递归 CTE 实现图谱遍历，成本降低 90% |
| 语义向量 | **Vectorize** | Pinecone / PGVector | Cloudflare 原生，与 Workers 零延迟集成 |
| PDF 原文 | **R2** | S3（需额外配置） | R2 免出口流量费，与 CDN 深度集成 |
| 会话状态 | **Workers KV** | Redis（需自建） | KV 全球低延迟，适合存储 Agent 对话上下文 |

### 2.3 图谱实现策略：D1 递归 CTE vs Neo4j

**决策**：使用 D1 + 递归 CTE 替代 Neo4j。

**理由**：
- Neo4j 的 Cypher 查询确实更优雅，但 D1 的 `WITH RECURSIVE` 足以覆盖 LexNusa 的核心查询场景（上下位法追溯、关联法规查询）。
- D1 的免费额度（5GB 存储 + 250 万行读/天）完全覆盖 17 万法规的数据规模。
- 避免引入额外图数据库的运维复杂度和成本。

**示例对比**：

| 查询需求 | Neo4j (Cypher) | D1 (SQL + CTE) |
| :--- | :--- | :--- |
| 查找某法规的上位法 | `MATCH (c:Law)-[:AMENDS*]->(p:Law) RETURN p` | `WITH RECURSIVE ... JOIN edges ...` |
| 查找关联法规（2 跳以内） | `MATCH (n)-[:REFERENCES*1..2]-(m) RETURN m` | `WITH RECURSIVE ... UNION ... LIMIT 2` |

### 2.4 前端框架选型

| 前端应用 | 框架选型 | 理由 |
| :--- | :--- | :--- |
| 网页一：图谱浏览器 | **React + Vite + D3.js** | D3.js 是关系图谱可视化的事实标准，React 生态丰富 |
| 网页二：Agent 平台 | **React + Vite + TailwindCSS** | 对话界面需要快速迭代，Tailwind 提升 UI 开发效率 |

### 2.5 协议层选型

| 协议 | 实现方案 | 端点 |
| :--- | :--- | :--- |
| **MCP（模型上下文协议）** | Streamable HTTP（MCP 现行规范；SSE 传输已弃用） | `https://mcp.lexnusa.workers.dev/mcp` |
| **A2A（智能体间通信）** | JSON-RPC over HTTPS（Google A2A 草案） | `https://a2a.lexnusa.workers.dev/discover` |

## 4. 安全架构

| 层级 | 安全措施 |
| :--- | :--- |
| **前端 - 网页一/二** | 所有 API 请求通过 Cloudflare 边缘，自动启用 HTTPS |
| **后端 - Workers** | 使用 Cloudflare Access 或 API Token 进行身份验证（企业版） |
| **数据 - D1** | 默认加密存储，支持备份与恢复 |
| **数据 - R2** | 加密存储 + 预签名 URL 控制访问 |
| **私有知识库** | 企业自有 Obsidian 笔记，数据不离开企业环境 |

## 5. 成本分析（Cloudflare 免费额度足够启动）

| 服务 | 免费额度 | LexNusa 预估用量 | 超出成本 |
| :--- | :--- | :--- | :--- |
| **Workers** | 10 万次请求/天 | 初期 1-2 万/天 | $0.30/百万请求 |
| **D1** | 5 GB 存储 / 250 万行读/天 | 2 GB / 50 万行/天 | $0.75/GB/月 |
| **Vectorize** | 100 万向量索引/月 | 50 万条 | $0.50/百万向量/月 |
| **R2** | 10 GB 存储 + A 类操作免费 | 5 GB | $0.015/GB/月 |
| **Pages** | 无限请求 + 500 构建/月 | 完全免费 | 无 |

**结论**：初期月成本 < $5，完全可承受。
