## 1. 产品概述

### 1.1 产品定位
LexNusa 是一个专为**出海印尼的中国企业**打造的智能法律合规中台。通过“知识图谱浏览器 + 多专家 Agent 平台”双网页形态，帮助企业法务、合规、业务团队快速理解和应用印尼法规。

### 1.2 核心价值
| 痛点 | LexNusa 解决方案 |
| :--- | :--- |
| 17 万+ 法规查找困难 | 结构化知识图谱 + 矢量语义检索，3 秒定位相关条款 |
| 法规频繁修订（如 UU Cipta Kerja） | 修订脉络追溯，自动标注“已废止/已被修订”状态 |
| 印尼语语言障碍 | 支持中文/印尼语/英语三语检索与问答 |
| 企业内部经验无法沉淀 | Obsidian 本地知识库与企业私域数据无缝集成 |
| 多个法规交叉引用复杂 | 多专家 Agent 协作（公司法+税务+劳工），自动生成合规报告 |

### 1.3 目标用户画像
| 用户角色 | 使用场景 | 核心诉求 |
| :--- | :--- | :--- |
| **法务专员** | 日常合规审查、合同审核 | 快速查证法规原文及修订历史 |
| **合规经理** | 新政策影响评估、风险报告 | 多维度交叉分析，生成可审计的报告 |
| **业务负责人** | 投资决策、市场进入 | 用自然语言提问，获取可执行的合规建议 |
| **外部顾问** | 为客户提供印尼法律咨询 | 展示法规关系图谱，增强说服力 |

## 2. 功能模块

### 2.1 网页一：知识图谱浏览器

#### 2.1.1 用户故事
- **US-GRAPH-01**：*作为*法务专员，*我想要*输入关键词（中文/印尼语）搜索法规，*以便*快速找到相关条款。
- **US-GRAPH-02**：*作为*合规经理，*我想要*查看某法规的“上位法-下位法”关系树，*以便*理解法规的立法逻辑。
- **US-GRAPH-03**：*作为*业务负责人，*我想要*看到法规的修订时间线，*以便*确认当前生效版本。
- **US-GRAPH-04**：*作为*外部顾问，*我想要*通过点击图谱节点进行探索式浏览，*以便*发现意料之外的法规关联。

#### 2.1.2 功能列表

| 功能 | 优先级 | 描述 | 交互方式 |
| :--- | :--- | :--- | :--- |
| 多语言搜索 | P0 | 支持中文/印尼语/英语混合关键词检索 | 搜索框输入 + 自动补全 |
| 关系图谱可视化 | P0 | 将法规及其关系渲染为力导向图/树形图 | D3.js 交互（缩放、拖拽、点击展开） |
| 修订脉络追溯 | P1 | 以时间线形式展示法规的修订历史 | 点击“修订历史”按钮展示时间线 |
| 条款详情面板 | P0 | 展示法规全文、元数据、关联法规列表 | 点击图谱节点或搜索结果项 |
| 矢量语义检索 | P1 | 输入自然语言描述，返回语义相关条款 | 搜索框勾选“语义搜索”开关 |
| 混合检索 | P2 | 同时返回精确匹配 + 语义相关结果 | 默认开启，无需用户操作 |
| 书签与收藏 | P2 | 用户可收藏常用法规 | 点击“⭐ 收藏”按钮 |
| PDF 原文下载 | P1 | 提供法规 PDF 原文（如适用） | 点击“📄 下载 PDF”按钮 |

### 2.2 网页二：Agent 专家平台

#### 2.2.1 用户故事
- **US-AGENT-01**：*作为*合规经理，*我想要*向“公司法专家”Agent 咨询“设立 PMA（外商直接投资公司）的最低资本要求”，*以便*快速获得准确答案。
- **US-AGENT-02**：*作为*法务专员，*我想要*让“税务专家”Agent 分析一笔跨境交易的税务影响，*以便*评估合规风险。
- **US-AGENT-03**：*作为*业务负责人，*我想要*让“劳工专家”Agent 解释“裁员补偿”的计算规则，*以便*制定人员调整预算。
- **US-AGENT-04**：*作为*合规经理，*我想要*同时向“公司法专家”和“税务专家”提问，*以便*获得跨领域的综合合规意见。

#### 2.2.2 专家 Agent 定义

| Agent 名称 | 人设 Prompt（摘要） | 核心 Skill |
| :--- | :--- | :--- |
| **公司法专家** | “你是印尼公司法专家，精通 UU No. 40 Tahun 2007 及 UU Cipta Kerja 相关修订。回答需注明法条出处。” | `query_company_law`（查询公司法图谱）、`check_fdi_requirements`（FDI 要求检查） |
| **税务专家** | “你是印尼税务专家，熟悉 PP No. 9 Tahun 2021、PPh 和 VAT 相关规定。” | `query_tax_regulations`（税务法规查询）、`calculate_tax_liability`（税款计算） |
| **劳工专家** | “你是印尼劳工法专家，精通 UU No. 13 Tahun 2003 及相关司法解释。” | `query_labor_law`（劳工法查询）、`calculate_severance`（裁员补偿计算） |
